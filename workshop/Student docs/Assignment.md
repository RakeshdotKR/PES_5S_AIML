Assignment1 Day1: Prompt Engineering – Prompt Relay Activity

Problem Statement:

Develop and evaluate a prompt engineering solution that extracts action items from meeting notes using an iterative prompt improvement approach.

Consider a project review meeting where multiple team members discuss technical issues, agree on tasks, assign responsibilities, and establish deadlines. The objective is to design progressively improved prompts that enable an LLM to accurately identify and extract all action items from the meeting notes.

The activity should demonstrate the impact of the following prompt engineering techniques:

1. Baseline Prompt: Start with a vague prompt and observe the quality of the generated response.
2. Clear Instructions and Role Assignment: Improve the prompt by providing explicit instructions and assigning the LLM a relevant role.
3. Output Contract: Define a structured JSON output format containing the owner, task, and deadline for each action item.
4. Chain-of-Thought (CoT) Signal: Further refine the prompt by instructing the LLM to systematically identify commitment statements and extract the corresponding action items.
5. Evaluation: Compare the outputs generated at each stage and assess improvements in accuracy, completeness, consistency, and structure.

Expected Outcome:

- Understand how iterative prompt refinement improves LLM responses.
- Identify the importance of role assignment and clear instructions.
- Understand how output contracts help generate structured responses.
- Explore the use of reasoning instructions for complex information extraction.
- Evaluate the effectiveness of different prompt engineering techniques.
